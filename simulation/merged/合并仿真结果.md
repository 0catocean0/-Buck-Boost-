# 16V→28V输入不断电切换：实际仿真结果

日期：2026-10-27。环境：MATLAB R2021b，Simulink，Simscape Electrical Specialized Power Systems。

## 模型结构

用户提供的Buck与Boost功率级共用一个24V直流源，各自保留输出电容，分别经选档开关接同一个14Ω负载。根模型只有一个powergui及一个主Scope；两路功率级和控制分组保存。

保留电感22μH/74mΩ，Buck输出220μF/30mΩ，Boost有效输出40μF/10mΩ，以及原开关、二极管的导通近似参数。原单独的8Ω和14Ω满载电阻退出，支路各留10kΩ泄放。Boost开关近似60mΩ，Buck10mΩ，选档接触电阻均10mΩ。

为了避免未选中的开环支路失控，新增明确标记的等效反馈：电压PI、负载前馈、电流阻尼、轻载停脉冲，以及轻载积分复位。这不是TPS5450或TPS55340的宏模型，不能替代其实际内部控制、补偿和保护验证。

## 测试工况

- 输入24V始终接通。
- 初始条件代表已经上电的状态：两路输出电容初值分别16V、28V，16V档已接负载，28V档待机；不验证零电压冷启动。
- 20ms断开16V，20.05ms接通28V，中间50μs两只选档开关均断开。
- 公共端不加大电容，使用纯14Ω负载。因此断开期间电压降到接近0，不能称为无缝切换。
- 16V档电流约1.14A，28V档约2A；这项切换测试不替代16V/2A的独立满载试验。

## 实际测量

稳态统计区间：切换前15～19ms，切换后35～39ms。下列公共输出包含选档开关的压降。

| 项目 | 结果 |
|---|---:|
| 切换前公共输出平均电压 | 15.995661V |
| 切换后公共输出平均电压 | 27.970262V |
| 切换后公共负载平均电流 | 1.997876A |
| 16V稳态窗口电压峰峰值 | 15.596468mV |
| 28V稳态窗口电压峰峰值 | 42.302014mV |
| 50μs断开期间公共输出 | 约0.000617V，由模型微小漏电决定 |
| 接入28V后公共输出最低值 | 27.473773V |
| 接入28V后公共输出最高值 | 28.170637V |
| 全时域Buck电感峰值 | 1.660963A |
| 全时域Boost电感峰值 | 2.923813A |
| 正式40ms运行警告 | 0 |

所选稳态窗口内，公共输出全部位于对应±2%电压范围。接入28V后记录到的样本也均处于27.44～28.56V范围，未发现需要等待其重新进入该范围的区间。这不表示没有动态暂态；动态最低点和最高点已列出，选档断开阶段的零电压也另行保留。

若任务书原文“100MV”最终确认是100mVpp，则当前两个稳态窗口的峰峰值均小于100mV；实际芯片、器件寄生、温升及示波器测量仍需单独验证。

## 数值与接线检查

保留500kHz和477.6kHz频率，公共数字时基为1/298.5MHz，两路分别每周期597、625点。测量日志每10个基础时步记录一次，约33.50ns一个点。CSV的全时域展示另有约1μs抽样版本，精细切换和稳态窗口保留完整日志采样。

将电气求解步长减半，数字控制时钟及PWM频率保持不变，另做两次相同的短时切换检查：稳态平均电压差约0.656μV，峰峰值差约0.443%；无运行警告。

公共负载关系 `Iload=Vload/14` 的最大数值误差约1.84×10^-12A；断开区间输出低于0.01V，验证了先断后合的效果。

初轮等效控制出现持续振荡，已通过修正轻载门控与调整控制参数消除；本报告和交付模型只使用修正后实际通过检查的结果。

## 控制参数与边界

- Buck等效电压PI：P=0.02，I=40；Boost：P=0.005，I=80。
- 电流阻尼系数0.04，电压采样低通20μs，电流采样低通0.5μs。
- 负载电流小于0.1A时复位PI积分，并采用电压上限停脉冲；带载时由连续稳压环调节。
- 占空比限制0～0.85，PI修正量限制−0.2～0.3。
- 这些参数仅属于本次等效仿真，不能直接转化为TPS55340的COMP阻容，亦不是单片机程序。
- 未验证机械触点抖动、容性负载回灌、反向28→16V切换、冷启动、真实器件限流和热性能。之前发现的Boost冷启动问题仍需独立处理。
