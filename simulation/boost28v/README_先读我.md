# 24V→28V升压仿真：打开与运行

完成日期：2026-10-27。环境：MATLAB R2021b、Simulink、Simscape Electrical Specialized Power Systems（SPS）。

这是已实际运行的开关功率级等效模型，采用开环PWM及占空比缓升；不是TPS55340的厂商模型，不包含其内部稳压、峰值电流控制、限流、热保护或真实软启动电路。

## 最简单的打开方式

1. 在MATLAB中打开本目录的 `Boost_24V_28V_equiv_v1.slx`。
2. 点击模型中的运行按钮。默认仿真时间20ms。
3. 双击 `Scope_Vout_Iout_IL`，从上到下是输出电压、负载电流、电感/输入电流。Scope自动缩放后可看完整波形。
4. 模型参数已保存在模型工作区，直接运行SLX不需要先执行其他脚本，也不需要TPS55340芯片库。

若希望同时自动导出数据、计算指标和生成图，在MATLAB中把当前文件夹切换到本目录，执行：

```matlab
run_boost28v_equiv
```

附加检查（步长减半、冷启动、略高于2A工作点）：

```matlab
validate_boost28v_equiv
```

只重新绘图，不重新仿真：

```matlab
plot_boost28v_results
```

从代码重新搭建模型（会重建本工具生成的同名模型；请先另存自己的修改）：

```matlab
build_boost28v_equiv
```

## 重要的初始条件

默认工况假设24V输入已接通，输出电容经电感、二极管预充到约23.375V。因此波形从约23.4V开始，3ms开始投入PWM，占空比在5ms内升到21/128（16.40625%）。这不是从0V冷启动。

另做的零电压冷启动诊断得到：输出峰值41.337V、开关节点峰值41.840V、电感峰值29.369A。此工况的电源被建模为理想阶跃，且没有输入阻抗、浪涌限制、电感饱和及芯片保护。这些峰值不是硬件实测，也不是可靠的实物峰值预测；它们揭示了被动充电路径的启动问题。该工况不能判定为设计通过，实物上电方案还须完善。

## 文件说明

- `Boost_24V_28V_equiv_v1.slx`：可编辑模型。
- `build_boost28v_equiv.m`：从零重建模型的函数。
- `run_boost28v_equiv.m`：运行、测量和保存主工况。
- `plot_boost28v_results.m`：读取主数据重新绘图。
- `validate_boost28v_equiv.m`：步长及冷启动检查，同时调用2A工作点检查。
- `check_boost28v_2A.m`：13.9Ω附加工作点。
- `28V升压仿真结果说明.md`：原理、参数、结论及限制，可用于整理实验报告。
- `boost28v_model.png`：模型接线图。
- `boost28v_results.png/.pdf`：主工况波形，PDF可插入报告。
- `boost28v_coldstart.png/.pdf`：冷启动问题诊断波形。
- `boost28v_metrics.json`、`boost28v_validation.json`、`boost28v_2A_check.json`：实际计算结果。
- `boost28v_steady_100cycles.csv`：稳态100个周期、每步记录的原始采样。
- `boost28v_main_data.mat`、`boost28v_coldstart_data.mat`：完整原始数据，保存在本地文件夹。精简ZIP不含这些较大的文件，运行脚本会重新生成。

## 改参数

在模型的“建模→模型资源管理器→模型工作区”修改 `p_` 开头的参数。默认负载 `p_Rload=14`，电感 `p_L=22e-6`，电容 `p_C=40e-6`。

PWM载波使用128个居中采样点。`p_Ts=1/(477600*128)`，`p_pwmSteps=128`，`p_D=21/128`。不能只改仿真步长而不相应调整载波采样点数，否则开关频率会改变。验证函数已同时调整这两个值。

本次未修改用户原有的16V降压模型。16/28V合并切换和实际芯片控制验证尚未完成。
